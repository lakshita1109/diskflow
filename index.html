Operating System Disk Scheduling Algorithms

Six fundamental I/O head positioning strategies implemented in modern OS kernels

FCFS

First Come First Serve

Services I/O requests strictly in chronological arrival order. Completely fair, eliminates starvation, but results in severe arm thrashing on scattered workloads.

Simulated Seek: —
SSTF

Shortest Seek Time First

Selects pending request closest to current head position. Dramatically reduces overall head movement, but causes starvation for distant cylinder requests.

Simulated Seek: —
SCAN

SCAN (Elevator)

Moves in one direction servicing requests until hitting the boundary cylinder, then reverses. Prevents starvation and provides bounded wait times.

Simulated Seek: —
C-SCAN

Circular SCAN

Moves in one direction to the end boundary, then immediately returns to the opposite boundary without serving on return. Provides uniform wait time distribution.

Simulated Seek: —
LOOK

LOOK Scheduling

Elevator variant that inspects pending requests ahead: reverses immediately at the furthest request in current direction without traveling to extreme disk edges.

Simulated Seek: —
C-LOOK

Circular LOOK

Restricts circular sweep only between lowest and highest requested tracks. Skips vacant boundary cylinders during turnaround, optimizing seek latency.

OPERATING SYSTEMS LABORATORY PROJECT

DISKFLOW

Interactive Disk Scheduling & I/O Performance Simulator

An advanced educational simulation designed for computer science and operating systems students to visualize mechanical hard drive head positioning, dissect seek latency mathematical models, and evaluate algorithm trade-offs under diverse I/O workloads.

Problem Statement & Motivation

In traditional spinning magnetic storage drives (HDDs), mechanical seek time—the physical movement of the disk read/write head assembly across concentric tracks (cylinders)—constitutes the primary bottleneck in secondary storage I/O performance.

Without intelligent scheduling, random first-come first-serve processing leads to severe arm thrashing, wherein the head continually swings across extreme ends of the platter, multiplying seek latency and sharply degrading system throughput.

Project Objectives

  • Provide an intuitive, interactive visual laboratory to model physical disk head mechanics.
  • Faithfully implement the 6 core OS disk scheduling algorithms (FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK) without mathematical approximations.
  • Quantify performance through rigorous metrics: Total Head Movement, Average Seek Distance, Estimated Seek Time, and Throughput.
  • Demonstrate multi-application OS workload multiplexing using Fair and Priority dispatching models.

Mathematical Formulations

1. Total Head Movement (Δ tracks)
Total Head Movement = Σi=1..N |Tracki - Tracki-1|

Sum of absolute displacements across all consecutive head cylinder transitions starting from initial head position.

2. Average Seek Distance (tracks/request)
Average Seek Distance = Total Head Movement / Total Serviced Requests

The expected seek travel required to service an individual I/O request.

3. Estimated Seek Time (ms)
Estimated Seek Time = Total Head Movement × Seek Time Per Track (ms)

First-order linear model calculating cumulative mechanical arm transition delay.

4. Simulated Throughput (requests/sec)
Throughput = Requests Serviced / (Total Seek Time + Rotational Overhead)

Educational estimate modeling completed I/O operations per simulated unit of real time.

In-Depth Algorithm Architectural Comparison

Algorithm Core Strategy Primary Advantage Major Drawback Boundary Behavior Starvation Risk
FCFS FIFO chronological order Zero algorithmic overhead; perfectly fair High seek distance; arm thrashing Does not seek boundaries None
SSTF Greedy closest cylinder Significantly minimizes seek movement Starvation for peripheral track requests Does not seek boundaries High (peripheral tracks)
SCAN Bi-directional elevator sweep Eliminates starvation; smooth travel Unequal waiting time; sweeps empty tracks to 0 or Max Must touch disk boundary (0 or Max) None
C-SCAN Uni-directional circular sweep Uniform waiting time distribution across platter High return seek overhead across entire disk Touches both boundaries (0 and Max) None
LOOK Directional sweep with lookahead Eliminates pointless boundary visits of SCAN Requests at opposing ends experience latency Reverses at furthest pending cylinder None
C-LOOK Circular sweep with lookahead Eliminates redundant boundary seeks of C-SCAN Arm return jump still incurs seek cost Wraps directly between lowest & highest requests None

Key Learning Outcomes

  • Mechanical Trade-offs: Understand why greedy optimization (SSTF) maximizes local throughput but introduces fairness and starvation anomalies.
  • Elevator Mechanics: Grasp why directional sweeps (SCAN/LOOK) bounded seek variance and prevented arm whip in early mainframe storage subsystems.
  • Circular Uniformity: Recognize how C-SCAN and C-LOOK ensure deterministic response times for both interior and exterior cylinder tracks.
  • Software Separation: Distinguish operating system process-level dispatch priority from hardware device driver disk scheduling.

System Technical Architecture

  • Core Technologies: HTML5 Semantic Markup, CSS3 Variables & Flex/Grid, Vanilla JavaScript (ES2022+), Chart.js (v4.4.2).
  • Design System: Elegant Burgundy & Ivory theme (#722F37, #F6F1E7, #C78D75, #78866B).
  • Zero Dependencies: No heavy web frameworks, runs purely in-browser locally without backend servers or databases.
  • Deterministic Engine: Pure mathematical models ensuring 100% reproducible results for academic evaluations and viva demonstrations.
